# Pumpy

<img src="dist/icon-dumbbell-192.png" width="96" height="96" alt="Иконка Pumpy">

**[Открыть приложение](https://pumpy-workouts.zahar186.chatgpt.site)**

1324 упражнения, подбор тренировок под себя и история подходов. На iPhone: открыть в Safari → «Поделиться» → «На экран Домой».

Мобильное веб-приложение по дизайну Pumpy. Статические HTML/CSS/JS, без сборки и сторонних JavaScript-зависимостей.

## Возможности

- Свайпы упражнений, избранное и исключения, отмена последнего решения.
- Удаление из избранного/исключённых кнопкой или свайпом влево с кнопкой «Убрать»; упражнение становится нейтральным. Отмена удаления.
- GIF-анимации упражнений в карточке, деталях и активной тренировке. В ручном подборе отдельный предпросмотр с анимацией, техникой и кнопкой добавления.
- Только избранные, случайная или ручная тренировка. Множественный выбор мышц и оборудования, без дубликатов и исключённых упражнений.
- Замена отдельного упражнения с соблюдением режима и подтверждением сброса только его подходов.
- Пустые поля веса, десятичная клавиатура, запятая/точка, сохранение по подходам. История и продолжение после перезагрузки.
- localStorage на конкретном устройстве/браузере. Экспорт/импорт проверяемой резервной копии.
- Ярлык на домашнем экране iPhone через Safari. Интернет необходим; офлайн-режим и межустройственная синхронизация не заявляются.

## Проверки

`node --test tests/core.test.mjs` — 11 тестов генератора, фильтрации, замены, весов, статистики, резервных копий и каталога.

В браузере проверены: изображения упражнений, избранное, генерация при недостатке избранных, ввод 82,5 кг, сохранение и восстановление после перезагрузки, завершение и история, ручной предпросмотр/добавление, свайп строки влево, удаление и кнопка отмены. Интерфейс просмотрен на размере 393×852 и настольном размере. Физический iPhone не использовался.

## Медиа и данные

Источник — https://github.com/hasaneyldrm/exercises-dataset. MIT распространяется на данные. GIF загружаются напрямую из публичного репозитория, с оригинальным разрешением 180×180 и видимой атрибуцией © Gym visual. Это не заявление о передаче лицензии на медиа: условия правообладателя изложены в `dist/Dataset-NOTICE.txt`; перед коммерческим распространением необходимо проверить права на медиа.

## Запуск локально

Запустить статический HTTP-сервер из `dist/`. Можно разместить содержимое `dist/` на любом статическом хостинге.

```sh
python -m http.server 4173 --directory dist
```
После запуска открыть http://localhost:4173.
